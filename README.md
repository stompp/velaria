# Velaria: manuales

**Velaria es una empresa inventada.** Estos manuales son parte de un demo de la plataforma stomppai: los escribe
un generador a partir de un catálogo inventado de cubiertas de piscina y armarios de jardín. Ningún nombre, código,
texto ni imagen es de una empresa real, y nada de lo que dicen se debe usar para instalar o programar un producto.

Los manuales están en `manuales/`, cada uno en Markdown y en PDF. Los enlaza el asistente del demo.
